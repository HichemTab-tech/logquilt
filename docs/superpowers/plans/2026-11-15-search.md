# Transcript search implementation plan

**Goal:** Find messages, tool calls/output, and compaction summaries throughout an uploaded conversation.

**Architecture:** Index normalized transcript entries in browser memory. A compact search bar provides a case-insensitive literal query, one result per matching entry, previous/next buttons, clear, and a highlighted excerpt. Navigation uses the existing virtualizer to reveal the matching row without filtering the conversation.

**Tech stack:** Existing React, TypeScript, TanStack Virtual, pnpm, Prettier, and Vitest. No new dependencies.

## Scope and constraints

- The user confirmed messages, collapsed tool output, and compaction summaries are searchable.
- Keep normal tool previews collapsed. Show the selected result's excerpt above the transcript, including text hidden in collapsed previews.
- Preserve local processing, safe plain-text rendering, read-only conversations, and the absence of global shortcuts.
- Implementation choices: count matching entries rather than occurrences; wrap next/previous navigation; clear search when leaving/replacing a conversation; exclude thinking and internal metadata.
- Keep the complete conversation available for scrolling and retain bounded DOM rendering on long files.
- Work directly on `master` as previously requested. Preserve unrelated maintainer edits.

## Review focus

Search must not execute transcript markup, leak queries to requests/storage/URLs, lose focus while typing, navigate using stale results, or leave a distant result outside the viewport after measurement. Long individual entries must still expose their matching excerpt. Query text containing regular-expression syntax is literal.

## Verification and review

`pnpm check` passes: formatting, strict TypeScript, production build, and all 35 Vitest tests. Desktop and mobile layouts were inspected using synthetic transcripts. A 10,000-tool-entry synthetic search returned the correct result.

Independent review found one issue: multiline context could hide the selected excerpt highlight. A browser regression reproduced it; the preview now scrolls locally to its highlight whenever the selected result changes. The fix passed the regression, full suite, and follow-up review. No findings remain.
